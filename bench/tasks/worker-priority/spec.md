Feature request (operator): queue priority per named session is stored in workers.yaml under workers.priority.sessions, and today it can only be changed by editing the file by hand. Add a `pai worker priority` command group:
  pai worker priority [list]            show each session with a priority as `<SESSION>  <PRIORITY>` (two spaces), then a "default: normal" line
  pai worker priority set SESSION PRIORITY  (the two declared argument names are exactly SESSION and PRIORITY) PRIORITY is high|normal|low; setting normal removes the entry. On success print the line `<SESSION>: <PRIORITY> priority` (e.g. `Jobs: high priority`). Anything else is refused with exit 1 and the message `priority must be high, normal or low`, leaving the file unchanged
  pai worker priority clear SESSION     remove the entry; if the session has none, exit 1 with the message `no priority entry for session "<SESSION>"` (e.g. `no priority entry for session "Jobs"`)
