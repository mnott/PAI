## Fixes applied in this run

1. **RED, context growth.** `~/.claude/settings.json` env
   `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` 80 → 20 (backup
   `~/.claude/pai/backups/settings.json.2026-09-20T1300`). On the 1M window
   that asks the platform to compact near 200k instead of ~784k. The daemon's
   threshold handover (`src/hooks/ts/lib/context-fill.ts`) derives warmup
   (−100k) and refresh (−40k) from the trigger and already takes the lower of
   the measured history (~784k) and the configured value (`triggerSource:
   "measured-clamped"`), so the first compactions at 200k get a warmed
   handover; four tests pinning this 80 → 20 regime were added to
   `context-fill.test.ts` (hooks suite 192 → 195).
   Proof pending: the next `compact_boundary` event's `preTokens` must land
   near 200,000, and `pai audit tokens session` on that session must show
   avg ctx well under 140k. The memory note "compaction-trigger-moved" records
   that the override did not take effect before 2026-09-12; re-measure, do not
   assume.
2. **AMBER, first-turn overhead.** Removed the `session-commands` SessionStart
   hook (166 tokens, a third copy of the session commands already in the CORE
   skill and the PAI MCP instructions): settings.json entry, live symlink,
   hook source, build entry and setup step. Before: SessionStart hooks 2,201
   tokens across 18 hooks. After: the instrument counts 17 hooks
   (`2026-09-20-run5.md`); the token reading for a fresh launch is expected
   at 2,035 and must be confirmed by `pai audit tokens hooks` in the next
   session.
3. **Instrument gaps.** `pai audit tokens` gains `subagents`, `mcp`, per-turn
   context statistics in `session`, and `--record <dir>`; the review prompt
   now names the instrument so run 5 needs no ad-hoc scripts.
